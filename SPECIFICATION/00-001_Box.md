## G-001 — Box

### Definition

A **Box** is the fundamental unit of organization in NaturalBoxOS.

A Box is a directory containing exactly one file named `boxInfo`.

Every manageable object in NaturalBoxOS SHALL be represented as a Box.

### Purpose

A Box provides a single, uniform representation for every manageable object within NaturalBoxOS.

Applications, operating system components, user projects, configurations, and other manageable objects are represented as Boxes and are managed through the same architecture.

### Related Terms

- G-002 — boxInfo
- G-003 — BoxID
- G-004 — BoxType
- G-005 — BoxState

### Notes (Informative)

NaturalBoxOS introduces only one fundamental software object: the Box.

More specialized concepts are defined by the metadata contained within a Box rather than by introducing additional object types.
