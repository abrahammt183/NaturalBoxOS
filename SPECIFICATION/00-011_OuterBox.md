# G-011 — OuterBox

## Definition

An **OuterBox** is a child Box whose RealParentBox and FosterParentBox are different Boxes.

An OuterBox is created when its RealParentBox is an OpenBox.

## Purpose

An OuterBox allows a child Box to be shared by one or more RealParentBoxes.
